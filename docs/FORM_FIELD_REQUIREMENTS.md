# PHMS Form Field Requirements

| Form                | Required fields                                                | Conditional rules                                                                                                                                  | Server authority                                        |
| ------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Patient             | Name, sex, DOB **or** estimated age value/unit, allergy status | DOB and estimated age are mutually exclusive; allergy details required for `HAS_ALLERGIES`                                                         | API validates and derives display age                   |
| Clinic visit        | Branch, patient, consultation fee                              | Doctor assignment is optional                                                                                                                      | API owns visit number and workflow status               |
| Clinical assessment | Chief complaint, medication status, allergy status             | Medicine details required when taking medicines; allergy details required when allergies exist; systolic and diastolic BP must be entered together | API validates physiologic ranges                        |
| Lab order           | One or more active tests, priority                             | Clinical notes optional                                                                                                                            | API snapshots test name/type/schema                     |
| Sample collection   | One record per ordered test, sample condition                  | Rejection reason required for non-acceptable samples                                                                                               | API generates tube/sample IDs and controls recollection |
| Lab result          | Result status and type-specific value                          | Numeric requires numeric value; Select requires configured option; Panel requires configured required components                                   | Completed result cannot be silently overwritten         |
| Doctor completion   | Diagnostic outcome and disposition                             | Final outcome requires final diagnosis; follow-up/referral/transfer fields become required by disposition                                          | API controls completion state                           |
| Password change     | Current password, new password, confirmation                   | Confirmation must match and policy must pass                                                                                                       | API rate limits and revokes other sessions              |

Disabled buttons are usability only; every rule is also enforced by the API.
